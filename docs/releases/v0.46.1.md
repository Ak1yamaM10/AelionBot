# AelionBot v0.46.1

Windows 上应用内更新后重启更快。

## 简体中文

### 更新更快

- 内置的 152 套设计系统改为打包在应用资源里，安装目录的文件数从约 4650 个降到约 500 个。安装更新时逐个写入这些小文件原本要花十几秒。
- 安装更新时，应用退出前等待收尾的时间从最多 8 秒缩短到 2 秒，安装程序不必再等待或强行结束它。
- 从 0.46.1 再更新到下一个版本时效果最明显：这一次升级仍要由旧版本的卸载程序清理旧文件。

## English

### Faster updates

- The 152 bundled design systems are now packed into the app's resources, so the installation holds about 500 files instead of about 4,650. Writing those small files one by one used to take more than ten seconds of each update.
- While an update is being installed, the app waits at most 2 seconds for open work on exit instead of 8, so the installer no longer has to wait for it or end it.
- The difference shows most from the next update after 0.46.1, since this one still uses the previous version's uninstaller to clear the old files.
