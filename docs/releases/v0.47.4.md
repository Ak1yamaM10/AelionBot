# AelionBot v0.47.4

## 简体中文

### 网页读取

- 支持 Clash、Mihomo、sing-box 等代理的 fake-ip DNS：解析到 `198.18.0.0/15` 时不再误报“本机或内网地址”，网页读取和搜索可以正常走代理。
- 字面量私网 IP、云元数据地址和重定向目标仍会被拦截，SSRF 防护边界不变。

### 搜索

- 移除内置的 Bing、DuckDuckGo 和 Brave 搜索工具。网页搜索改由模型服务端内置搜索或已启用的搜索 MCP 提供，`web_read` 继续用于读取网页正文。
- 使用 OpenAI 兼容协议且没有配置搜索 MCP 的 Bot 将不再具备网页搜索能力；请启用搜索 MCP，或改用支持服务端搜索的 Provider。

## English

### Web reading

- Proxy fake-ip DNS answers in `198.18.0.0/15` (Clash, Mihomo, sing-box) are accepted instead of being reported as a local or private address, so page reads and searches can use the proxy normally.
- Literal private IPs, cloud metadata addresses and redirect targets remain blocked; the SSRF boundary is unchanged.

### Search

- Removed the built-in Bing, DuckDuckGo and Brave search tool. Web search now comes from the provider's hosted search or an enabled search MCP, while `web_read` still opens page content.
- Bots on an OpenAI-compatible provider without a search MCP no longer have web search; enable a search MCP or switch to a provider with hosted search.
