# AelionBot v0.44.1

插件页重新设计：连接器、MCP 和技能各用适合自己的样子展示，详情在右侧打开，列表不再被替换。

## 简体中文

### 插件页

- 顶部只留一个“添加”按钮，从菜单里选连接器、MCP 服务或技能文件夹。搜索框移到标题旁，按 Ctrl+K 可以直接搜索。
- 分类改为“概览 / 技能 / MCP / 连接器”标签，“来源与配置”和“重新扫描”放在标签行右侧。
- 连接器显示为状态卡片，带飞书、企业微信、微信的图标，写明账号、连接状态、对应的 Bot、会话数和最近一次消息；有配对请求时直接标出。还没有连接器时，点平台按钮就能开始添加。
- MCP 服务按行列出状态、工具数、连接方式和来自哪个配置。需要配置的服务直接写出原因，并给出“去配置”。多个配置里同名的服务合成一行，展开后分别开关。
- 技能按内置、各共享文件夹和各 Bot 私有分组，概览里每组先显示 6 个。内置技能有各自的图标，Bot 私有技能显示那个 Bot 的头像。卡片上显示用过几次、最近一次是什么时候，共享技能会把所有 Bot 的使用次数加在一起。
- 点开技能、MCP 或连接器，详情在右侧抽屉里显示，按 Esc 或点空白处关闭后回到原来的位置。技能详情分开显示 SKILL.md 和附带文件；连接器详情把配对请求放在最上面。
- 开关改成和应用一致的颜色，尺寸也小一些。

## English

### Plugins page

- A single "Add" button opens a menu for a connector, an MCP server or a skill folder. Search sits next to the title, and Ctrl+K jumps to it.
- Tabs for Overview, Skills, MCP and Connectors replace the filters; "Sources & configuration" and "Rescan" sit at the right of the tabs.
- Connectors appear as status cards with the Feishu, WeCom and WeChat icons, showing the account, connection state, Bot, number of chats and the last message, and flagging pairing requests. With no connectors yet, a platform button starts adding one.
- MCP servers are listed with their state, tool count, transport and the configuration they come from. A server that needs setup says why and offers "Set up". Servers with the same name from several configurations share one row that expands to switch each on or off.
- Skills are grouped into built-in, each shared folder and each Bot's private skills, six per group on the overview. Built-in skills have their own icons and private skills show their Bot's avatar. Cards show how often and how recently a skill was used; shared skills add up the use by every Bot.
- Skill, MCP and connector details open in a drawer on the right; Esc or a click outside closes it and returns to the same place. Skill details show SKILL.md and the attached files separately; connector details put pairing requests at the top.
- Switches use the app's own colors and are a little smaller.
