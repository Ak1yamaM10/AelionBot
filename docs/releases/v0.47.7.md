# AelionBot v0.47.7

## 简体中文

### 对话

- Bot 可以在回复里插入结构化块，并把块放在段落之间：模型返回块后用 `[[block:id]]` 指定位置，没指定位置的块追加在回答末尾。
- 支持图表（折线、柱状、堆叠柱、面积、饼图/环形、迷你趋势）、关键指标、可排序表格、时间线、提示块和可交互计算器。
- 计算器在本地完成计算，不产生模型调用；税率换算、贷款对比这类问题可以改数字直接看结果，也能复制当前结果。
- 块只是数据，不是 HTML 或脚本：应用按类型渲染，公式走白名单解析，单个块出错只降级成文字摘要，不影响整条回复。
- 飞书、企业微信和微信连接器收到的是块的文字摘要，不会出现内部标记。

### 说明

- 目前消息块在 Bot 主对话和工作会话中显示；群聊和 Bot 私聊暂未开放。
- 表格可点击表头排序，图表带可访问的文字摘要。

## English

### Chat

- Bots can place structured blocks inside a reply and between paragraphs: after returning a block the model writes `[[block:id]]` where it should appear, and blocks without a marker follow the answer.
- Supported blocks: charts (line, bar, stacked bar, area, pie/donut, sparkline), key metrics, sortable tables, timelines, callouts and interactive calculators.
- Calculators run locally without a model call, so tax or loan scenarios can be changed and read immediately, and the current result can be copied.
- Blocks are data, not HTML or scripts: the app renders each type, formulas go through a whitelisted parser, and a failing block degrades to its text summary without breaking the reply.
- Feishu, WeCom and WeChat connectors receive the plain-text summary of each block, never the internal markers.

### Notes

- Message blocks appear in a Bot's main conversation and work sessions; group chats and Bot-to-Bot private chats do not offer them yet.
- Tables sort by clicking a column header, and charts carry an accessible text summary.
