# AelionBot v0.47.6

## 简体中文

### 设置

- 设置页左栏重新整理为“工作区”和“系统”两组，使用线性图标；顶部显示 AelionBot 的标志。
- 用量页重新设计：新增筛选栏，以及总量、缓存、输入、失败率、本周期峰值和平均每次请求等汇总卡片；按模型和 Provider 的明细可以搜索。
- 用量页的下拉框按最长选项自动加宽，模型名不再被逐字换行。

### 对话

- 输入框旁的实时 tok/s 现在也计入思考和工具参数，模型在思考或写文件时同样会显示速度。
- 工作过程里读取图片的步骤直接显示图片；“应用文件补丁”改称“修改文件”。

### 设计任务

- 画布开着时，新消息不再自动算作设计任务的继续：Bot 只在你要修改设计稿时接上这个任务，把设计落地到代码等其他工作按普通任务处理，设计任务也不会一直显示“正在设计”。
- 聊天里每个设计任务的卡片只显示一次，位于最近一次相关的运行下方。

### 问题修复

- 修复使用 DeepSeek 思考模式时，上下文压缩过的对话在参考资料变化后（例如开始设计任务）报 HTTP 400 “reasoning_text must be passed back”、无法继续的问题。已经出现这个错误的对话，更新后点“继续处理”即可恢复。

## English

### Settings

- The settings rail is regrouped into Workspace and System with line icons, and shows the AelionBot mark at the top.
- The usage page is redesigned with a filter row, summary cards for total, cache, input, failure rate, period peak and average per request, and a searchable breakdown by model and provider.
- Usage dropdowns widen to their longest option, so model names no longer break one character per line.

### Chat

- The live tok/s beside the composer now counts reasoning and tool arguments, so it also shows while the model thinks or writes files.
- Image steps in the work process show the image itself; "Apply file patch" is now "Edit file".

### Design tasks

- With the canvas open, a new message no longer continues the design task automatically: the Bot picks the task up only when you ask to change the design, other work such as building it into code runs as an ordinary task, and the task no longer stays on "Designing".
- Each design task's card appears once in the chat, under its latest run.

### Fixes

- Fixed DeepSeek thinking mode rejecting a compacted conversation with HTTP 400 ("reasoning_text must be passed back") after its reference changed, for example when a design task started. Conversations already showing this error recover with Continue after updating.
