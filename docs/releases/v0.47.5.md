# AelionBot v0.47.5

## 简体中文

### 应用连接

- 新增 DeepSeek 应用（插件页“连接器 → 资料检索”）：填入 DeepSeek API Key 后，Bot 可以用 DeepSeek 搜索网页和抓取网页正文。
- 搜索支持 `site:`、`lang:`、`after:` 等运算符，结果带相关度和权威度；抓取的长网页分页读取，翻页不会重复计费。
- API Key 加密保存在本机。DeepSeek 按成功请求计费（搜索、抓取各 5 元 / 千次），余额不足或 Key 无效时会直接告诉 Bot 原因。
- 使用 OpenAI 兼容协议、没有服务端搜索的 Provider，可以用它恢复网页搜索。

## English

### App connectors

- Added a DeepSeek app (Plugins → Connectors → Reference): with a DeepSeek API key, Bots can search the web and fetch page content through DeepSeek.
- Search supports operators such as `site:`, `lang:` and `after:`, and results carry relevance and authority scores; long fetched pages are read in pages without being billed again.
- The API key is stored encrypted on this computer. DeepSeek bills successful requests (5 CNY per 1,000 searches or fetches); an invalid key or low balance is reported to the Bot as such.
- Providers on the OpenAI-compatible protocol without hosted search can use it to get web search back.
