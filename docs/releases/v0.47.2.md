# AelionBot v0.47.2

## 简体中文

### 币安应用

- 应用列表新增 Binance，可通过币安官方 MCP 在浏览器中授权连接，无需手动填写 API Key。
- 支持查询行情与 Agentic 子账户信息，并根据币安授权范围使用现货、杠杆、闪兑、U 本位及币本位合约和子账户内部划转。实际可用功能取决于地区、账户资格及授予的权限；此入口不包含 Binance Web3 钱包。

### OAuth 连接

- 新增公开客户端元数据（CIMD）支持，兼容币安的 OAuth 授权和 PKCE 校验，沿用系统加密存储凭据。
- 使用固定回调地址的连接在本机端口被占用时提示重试，避免切换到未登记的回调地址。

## English

### Binance app

- Added Binance to the app catalog, with browser authorization through the official Binance MCP server and no API key to enter manually.
- Access market data and Agentic sub-account information, with Spot, Margin, Convert, USDⓈ-M and COIN-M Futures, and transfers within the sub-account where authorized. Availability depends on region, account eligibility and granted permissions. This connector does not include Binance Web3 Wallet.

### OAuth connections

- Added Client ID Metadata Document (CIMD) support for Binance OAuth and PKCE, retaining encrypted credential storage through the system key store.
- Connections with a fixed callback address report a busy local port instead of switching to an unregistered callback.
