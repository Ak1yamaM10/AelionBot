# AelionBot v0.45.0

连接应用：在插件页登录 Notion、GitHub、Google、Supabase 等 74 个应用，Bot 就能直接用它们的工具。

## 简体中文

### 连接应用

- 插件页 → 添加 → 应用，打开应用目录，按“文档与协作、Google、开发与数据、产品分析、设计与内容、销售与营销、支付与商务、资料检索”分组，可以搜索。
- 大部分应用点一下就在浏览器里登录，不需要自己申请密钥。登录凭据加密保存在这台电脑上，过期后自动续期。
- GitHub 用访问令牌连接；Gmail、Google Drive、日历、文档、表格、幻灯片需要你在自己的 Google Cloud 项目里建一个 OAuth 客户端，对话框里有分步说明，设置一次后所有 Google 应用共用。
- Context7、DeepWiki、Exa、Microsoft Learn、AWS 文档、Hugging Face 等不需要账号，标有“免登录”。
- 从 Claude、Cursor 等配置里读到的远程 MCP 服务，需要授权时也可以在插件页直接登录。
- “连接器”分页分成“应用”和“消息渠道”两部分，飞书、企业微信、微信放在“消息渠道”里；MCP 分页只列其余的服务。

### Bot 使用 MCP

- 已连接服务的工具直接出现在 Bot 的工具列表里，名称形如 mcp__notion__search，带服务自己的参数说明，一次调用即可完成。
- Bot 的上下文里有一份已启用服务的清单，写明每个服务的用途、是否需要登录，以及服务自带的使用说明。
- 启用的服务会在应用启动、启用、登录后在后台自动连接。本机运行的 MCP 服务因此会在启动时就运行它的命令。
- 工具调用仍然按原来的权限模式审批。

### 修复

- 在工作会话里让 Bot 给其他 Bot 发私信，回复现在回到这个工作会话，而不是主会话；来自飞书、企业微信、微信的会话也会把回复发回聊天。
- 技能清单里的用途描述最多保留 1024 字，原来只有 160 字。

## English

### Connect apps

- Plugins → Add → App opens a catalog of 74 apps, grouped into docs and teamwork, Google, development and data, product analytics, design and content, sales and marketing, payments and reference, with search.
- Most apps sign in with one click in your browser, without creating keys yourself. Sign-ins are kept encrypted on this computer and renewed when they expire.
- GitHub connects with an access token. Gmail, Google Drive, Calendar, Docs, Sheets and Slides use an OAuth client you create in your own Google Cloud project; the dialog walks through it, and every Google app shares it.
- Context7, DeepWiki, Exa, Microsoft Learn, AWS Docs, Hugging Face and others need no account and are marked as such.
- Remote MCP servers found in Claude, Cursor and other configurations can be signed in to from the Plugins page when they need authorization.
- The Connectors tab is split into Apps and Messaging, which holds Feishu, WeCom and WeChat; the MCP tab lists the remaining servers.

### MCP for Bots

- Tools of connected servers appear in a Bot's tool list under names such as mcp__notion__search, with the server's own parameters, and run in one call.
- A Bot's context lists the enabled servers: what each is for, whether it needs a sign-in, and the instructions the server provides.
- Enabled servers connect in the background at startup, when enabled and after sign-in. Local MCP servers therefore run their command at startup.
- Tool calls are still approved under the Bot's permission mode.

### Fixes

- When a Bot in a work session messages another Bot, the reply now comes back to that work session instead of the main chat; sessions from Feishu, WeCom and WeChat also send it back to the chat.
- Skill descriptions in the skill list keep up to 1024 characters instead of 160.
