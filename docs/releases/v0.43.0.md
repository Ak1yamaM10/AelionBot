# AelionBot v0.43.0

这一版让 Bot 可以操作你这台 Windows 电脑上的应用，重新设计了对话和设置界面，并让群聊和狼人杀更少被占位消息和服务商故障打断。

## 简体中文

### 本机电脑控制

- 在 设置 → 权限 打开“让 Bot 操作这台电脑上的应用”后，Bot 可以操作这台电脑上的应用窗口：查看窗口、启动应用、点击、拖动、滚动、输入文字和按键，也可以按控件编号操作，不必猜坐标。默认关闭，目前只支持 Windows。
- 每个任务第一次要操控电脑时会请你确认一次，允许后这个任务里不再询问；拒绝后这个任务不会再问。这项确认不受本机权限模式影响，完全访问模式下也要确认。
- Bot 使用真实的鼠标和键盘，操作期间屏幕边缘有紫色边框和提示条，按 `Esc` 立即停止任务。同一时间只有一个任务能操控电脑。
- 终端应用、AelionBot 自身和以管理员身份运行的窗口不能操作，Windows 键组合和 `Alt+Tab` 这类会离开当前应用的快捷键不会发送。截图只包含目标应用自己的窗口，点击或输入落到其他应用上时会被拒绝。
- 无人值守运行不提供这个能力。

### 批量操作

- 工作电脑和本机的电脑操作都可以一次连续执行最多 20 个动作，例如点击输入框、输入、回车，只在最后截一张图。所有步骤先检查再执行，中途失败时会说明是第几步。

### 对话

- 对话改为白色气泡，侧栏和顶栏是白色外框；同一方连续发出的消息会合成一组。
- 每个气泡显示发送时间。在 Bot 私聊里，一组消息的最后一条旁边显示 Bot 的头像。
- 文件以缩略图显示在气泡下方，文本文件显示开头几行；图片仍按拼图排列。
- 鼠标悬停时，气泡边缘出现工具栏，可以直接选常用表情、打开表情选择、回复或复制。
- 定时任务触发时显示为一张卡片，带任务名称，指令折叠为两行，可以展开全文。
- 设置 → 外观 新增“对话背景”，有七种色调可选，只影响浅色主题，默认纯白。

### 设置

- 设置窗口重新设计：左侧是分组导航，顶部是你的个人资料；所有页面使用统一的卡片、行、输入框和开关。
- 外观页带实时对话预览；电脑页有状态卡片和分段的存储空间条；记忆页按 Bot 头像切换；用量页把各项数字放在同一张卡片里，并配面积图。
- 模型服务商和个人资料使用自动生成的图标。

### 群聊

- 新增 `group_pass`：Bot 没有要说的话时可以明确跳过本轮，不再发出“（不发言）”“[No content]”这类占位消息。被点名或被提问的 Bot 跳过前会收到一次提醒；群里还有未完成的计划或待发布的文件时不能跳过。
- 只声明不发言或“本轮无新增内容”的回复、整条包在 `<…>`、`[…]`、`【…】` 或 `*…*` 里的短舞台说明，以及照抄收件记录的回复，不再发到群里，也不会唤醒其他成员。带问题、@、提醒或实际内容的回复照常显示。

### AI 游戏

- 狼人杀对局更不容易因为一次模型失误而暂停：动作里多余的字段会被忽略，过长的文字会被截短，写成座位号的目标会对应到相应座位。
- 服务商限流、5xx 和网络错误最多尝试 4 次，间隔 2、8、30 秒，服务商给出 `Retry-After` 时按它等待；密钥无效、参数不支持这类错误立即暂停。
- 暂停提示显示服务商名称、HTTP 状态码和服务商返回的错误信息，例如“OpenRouter 暂时不可用（HTTP 503：Service temporarily unavailable）”，不再显示原始响应内容，其中类似密钥的内容会被遮盖。

### 修复

- 切换界面语言后，下拉框按钮上的文字会随之更新。

## English

### Computer use on this computer

- Turn on "Let Bots use apps on this computer" in Settings → Permissions and a Bot can operate app windows on this computer: look at windows, start apps, click, drag, scroll, type and press keys, or act on a control by its number instead of guessing coordinates. It is off by default and Windows only for now.
- The first time a task wants to control the computer, you are asked once. After you allow it, that task does not ask again; after you refuse, it does not ask again either. The question does not depend on the permission mode and is asked in Full access as well.
- The Bot uses the real pointer and keyboard. While it works, a purple border and a status pill show on screen, and `Esc` stops the task at once. Only one task can control the computer at a time.
- Terminal apps, AelionBot itself and windows running as administrator cannot be operated, and shortcuts that leave the app, such as Windows-key chords and `Alt+Tab`, are not sent. Screenshots hold only the target app's own windows, and clicks or typing that would land on another app are refused.
- Unattended runs do not offer it.

### Batched actions

- Computer actions on the work computer and on this computer can run up to 20 steps in one go, such as clicking a field, typing and pressing Enter, with a single screenshot at the end. Every step is checked before the first one runs, and a failure names the step.

### Chat

- Chats use white bubbles inside a white frame (sidebar and header), and consecutive messages from one side group together.
- Each bubble shows when it was sent. In a Bot's own chat, its avatar stands beside the last message of a group.
- Files sit below the bubble as thumbnails, and text files show their first lines; images keep the mosaic.
- On hover, a toolbar on the bubble's edge offers quick reactions, the emoji picker, reply and copy.
- A scheduled task firing shows as a card with the task's name and the instruction folded to two lines, expandable to the full text.
- Settings → Appearance has a new conversation background with seven tones. It applies to the light theme and defaults to white.

### Settings

- The settings window is redesigned: grouped navigation on the left with your profile at the top, and every page built from the same cards, rows, fields and switches.
- Appearance has a live chat preview, Computer has a status card and a segmented storage bar, Memory switches Bots by avatar, and Usage shows its figures in one card with an area chart.
- Model providers and your profile get generated emblems.

### Group chats

- New `group_pass`: a Bot with nothing to say skips its turn explicitly instead of posting placeholders such as "（不发言）" or "[No content]". A Bot that was addressed or asked a question gets one reminder before it may pass, and it cannot pass while the group still has an unfinished plan or files to publish.
- Replies that only declare silence or "nothing new", short stage directions wrapped entirely in `<…>`, `[…]`, `【…】` or `*…*`, and replies that copy an inbox record are no longer posted and no longer wake other members. Replies with a question, an @, a caveat or real content stay visible.

### AI games

- Werewolf matches pause less often over a single model slip: extra fields in an action are ignored, overlong text is shortened, and a target written as a seat number maps to that seat.
- Rate limits, 5xx and network errors get up to 4 attempts with 2, 8 and 30 second waits, or the provider's `Retry-After`. Errors such as an invalid key or an unsupported parameter pause at once.
- The pause notice names the provider and the HTTP status and shows only the provider's own error message instead of the raw response body, with key-like text masked.

### Fixes

- Select buttons update their text when you switch the interface language.
